# AnswerGraph — Modern AEO, GEO & SEO Engine for WordPress

Plugin WordPress untuk Generative Engine Optimization (GEO), Answer Engine Optimization (AEO), Entity SEO JSON-LD, LLMs.txt Manager, IndexNow, AI Bot Telemetry & Activity Log, Linter Regulasi, dan Auto-Updater 1-klik langsung dari dashboard WP Admin.

## Fitur Utama (v2.1.0)
- **Live GEO & AEO Analyzer** di editor Classic (Text/Visual) & Gutenberg.
- **Linter Regulasi ESDM (Opsional) & Kata Terlarang Kustom** + **Freshness Tracker** (`Segar` / `Usang > 180 hari`) di Bulk Content Audit.
- **Pillar Internal Linker** di metabox editor untuk menyalin HTML anchor link internal secara cepat.
- **IndexNow Auto-Ping & Key Verifikasi** otomatis saat post/page diterbitkan atau diperbarui.
- **AI Bot Telemetry & System Activity Log** (50–100 entri terakhir, `autoload=false`, dilengkapi tombol reset log).
- **Markdown Discovery Headers** (`<link rel="alternate" type="text/markdown">` & `X-LLMs-Txt`) + `?format=llm-md`.
- **LLMs.txt & LLMs-full.txt Manager** terintegrasi (sinkronisasi langsung ke root WordPress + endpoint virtual fallback).
- **Entity Disambiguation (`sameAs` Schema)**, pengganti nama author internal, & dropdown Schema `Course` / `Service` per halaman.
- **1-Click WordPress Auto-Updater** melalui GitHub Releases atau manifest JSON.

## Instalasi
1. Unduh `answergraph.zip` dari tab [Releases](https://github.com/DimasAkbarF/AnswerGraph/releases).
2. Di WP Admin buka **Plugins → Add New → Upload Plugin**, lalu aktifkan.
3. Update versi berikutnya cukup klik **Cek Update** → **Update Now** langsung di halaman **Plugins** WP Admin.
