# AnswerGraph — Modern AEO, GEO & SEO Engine for WordPress

Plugin WordPress untuk Generative Engine Optimization (GEO), Answer Engine Optimization (AEO), Entity SEO JSON-LD, LLMs.txt Manager, Linter Regulasi ESDM, dan Auto-Updater 1-klik langsung dari dashboard WP Admin.

## Fitur Utama (v2.0.0)
- **Live GEO & AEO Analyzer** di editor Classic (Text/Visual) & Gutenberg.
- **Linter Regulasi ESDM & Anti-AI-Slop** real-time (Permen ESDM 10/2021 Pasal 26/28, >= 5 MW, >= 200 kVA, masa berlaku SKTTK 3 tahun, atribusi LSSM KAN, dan deteksi frasa klise).
- **LLMs.txt & LLMs-full.txt Manager** terintegrasi (sinkronisasi langsung ke root WordPress + endpoint virtual fallback).
- **Entity Disambiguation (`sameAs` Schema)**, pengganti nama author internal, & dropdown Schema `Course` / `Service` per halaman.
- **Bulk Content Audit Dashboard** untuk memindai skor GEO/AEO seluruh artikel & halaman.
- **1-Click WordPress Auto-Updater** melalui GitHub Releases atau manifest JSON.

## Instalasi
1. Unduh `answergraph.zip` dari tab [Releases](https://github.com/DimasAkbarF/AnswerGraph/releases).
2. Di WP Admin buka **Plugins → Add New → Upload Plugin**, lalu aktifkan.
3. Update versi berikutnya cukup klik **Cek Update** → **Update Now** langsung di halaman **Plugins** WP Admin.
